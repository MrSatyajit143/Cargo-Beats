## 🚀 Deploy in 5 Steps

### **Step 1: GitHub Account**
- https://github.com/signup
- Username + Email create karo

### **Step 2: New Repository**
- Click "+" → New repository
- Name: `cargo-beats`
- Public ✅
- Create ✅

### **Step 3: Upload Files**
- "Add file" → "Upload files"
- Teeno files select: index.html + manifest.json + service-worker.js
- Commit ✅

### **Step 4: Enable Pages**
- Settings → Pages
- Source: Main branch
- Save ✅

### **Step 5: Share Link**
- URL: `https://username.github.io/cargo-beats`
- (Apna GitHub username lika de)

## 📱 Install on Phone
